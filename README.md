# FarmLease-A-Digital-Agricultural-Land-Leasing-Platform
A full-stack web platform designed to revolutionize agricultural land leasing in Ethiopia. It connects verified farming clusters with investors through a transparent, secure, and AI-powered digital ecosystem.

#Key Features:

Cluster & Farmer Registration with Geospatial Verification
Investor Proposal Submission & Structured Negotiation
Digital Agreement Generation & Simulated Signing
Receipt-based Payment Verification System
AI Chatbot & Cost/Yield Prediction Analytics
Role-Based Access Control (RBAC) for Farmers, Representatives, Investors & Admins

Built as a Bachelor’s Degree Final Year Project at Adama Science and Technology University using Next.js/React, Django/Node.js, and PostgreSQL.
#Tech Stack: Next.js | Django | PostgreSQL | AI/ML | Leaflet Maps | RBAC
